# apps/web

React + Vite + TypeScript. Montado na etapa 0 a partir de `docs/prototipo.html`, que é a referência visual oficial.

- Tokens e regras em `docs/03-design.md`.
- Navegação com `data-v="<tela>"` nos itens da barra lateral, pra o `npm run testar:layout` conseguir passar por todas as telas.
- Floresta e pinheiros com `data-ignorar-layout` (podem vazar de propósito).
- Antes de terminar qualquer mudança visual: `npm run testar:layout`.
